كل نشاط يشوف أدواته فقط

العميل يختار نوع نشاطه عند التسجيل، فتظهر له الأدوات التي يحتاجها وتختفي الباقية. محل الملابس لا يرى المطبخ، والصالون يبدأ يومه من التقويم، والبقالة تبيع بالميزان وتنبّه على الصلاحية. هذا تقرير قبل البناء.

الوضع الحالي بصراحة

  • حقل business_type موجود بأربع قيم فقط (retail, food, services, mixed)، وتأثيره الوحيد اليوم هو إنشاء محطات المطبخ عند التسجيل.
  • شاشة Kitchen تظهر حسب الصلاحية فقط، يعني محل الريتيل يراها حالياً. هذا يُصلح في المرحلة A.

  • لوجو المحل لا يظهر على الفاتورة؛ رأس الفاتورة نص فقط. التصميم المقترح بالأسفل.

مثال توضيحي
  • رفع اللوجو (PNG / SVG / JPG) من Settings → Business & receipt.
  • يتحوّل تلقائياً إلى أبيض وأسود (dithering) بعرض 384px لورق 58mm و576px لورق 80mm، لأن الطابعة الحرارية لا تطبع الرمادي.
  • إظهار أو إخفاء، وثلاثة أحجام، ومعاينة مباشرة مثل إعدادات الفاتورة الحالية.
  • يظهر على: الفاتورة الحرارية عبر Branch Hub، فاتورة A4 / PDF، صفحة Payment link، والإيصال الرقمي.
  • الحجم: صغير، ضمن المرحلة A. الـ Hub يطبع الفاتورة كصورة أصلاً، فإضافة اللوجو لا تحتاج تغيير في الطابعات.

التكامل والذكاء

ثلاث إضافات على مستوى المنصة، متاحة لكل الأنشطة ويفعّلها العميل حسب طلبه.

WhatsApp

جديد

ربط رسمي عبر WhatsApp Cloud API من Meta، وكل عميل يربط رقمه التجاري الخاص.

  • فاتورة رقمية بعد البيع
  • "طلبك جاهز" للمغسلة والمطعم والصيانة
  • تذكير المواعيد وتأكيدها
  • إرسال Payment link
  • تنبيهات للمدير: نقص مخزون، إقفال وردية، فرق كاش

الرسائل التي يبادر بها المحل تحتاج قوالب معتمدة من Meta وتُحاسب Meta عليها مباشرة. ربط الرقم يتطلب توثيق حساب الأعمال لدى Meta لكل عميل.

n8n Automation

جديد

Z Trust يرسل أحداثاً موقّعة (HMAC webhooks)، ويستقبل أوامر عبر API keys بصلاحيات محددة.

  • sale.completed · stock.low · order.ready · shift.closed · appointment.booked · refund.created
  • قوالب n8n جاهزة: تقرير يومي للإيميل، تصدير لـ Google Sheets، ربط مع ERP أو CRM
  • سجل لكل إرسال مع إعادة المحاولة

يعمل مع n8n سحابي أو على سيرفر العميل، ويصلح أيضاً لـ Make وZapier.

المساعد الذكي Z Assistant

جديد

محادثة داخل الـ Dashboard بالعربي والإنجليزي، يشتغل بنموذج Claude عبر Edge Function.

  • ملخص صباحي: مبيعات أمس، مقارنة بالأسبوع الماضي، ما يحتاج انتباه
  • أسئلة حرة: "أكثر صنف خسرنا فيه هالشهر؟"، "مين أبطأ محطة بالمطبخ؟"
  • تنبيهات ذكية: ارتفاع الإلغاءات أو المرتجعات، أصناف قاربت الانتهاء، تأخر المطبخ
  • اقتراحات: كمية إعادة الطلب، أوقات الذروة للتوظيف

يقرأ فقط من نفس تقارير النظام وبصلاحيات المستخدم: الكاشير لا يرى أرقام التكلفة. كل رقم يذكره مربوط بتقريره، ولا ينفّذ أي عملية بدون تأكيد وموافقة PIN.

رأيي المهني

9 أنشطة للإطلاق وليس 18

تسعة أنشطة مكتملة أفضل من 18 نصف جاهزة. الباقي يُفتح كقوالب بعد ما تثبت الـ modules في السوق.

منتج واحد بـ Modules

لا نسخة منفصلة لكل نشاط. النسخ المنفصلة تضاعف الصيانة والاختبارات وتبطّئ كل تحديث.

الصيدليات والعيادات: تأجيل

تحتاج ربطاً مع جهات صحية وضوابط وصفات وسجلات طبية تختلف من دولة لأخرى. دخولها بدون ذلك مخاطرة نظامية.

الذهب: تحقق قبل البناء

التسعير بسعر اليوم سهل تقنياً، لكن معاملة VAT للذهب تختلف بين دول الخليج. أحتاج تأكيد محاسب لكل دولة قبل البناء.

الباقات والعربون التزامات

جلسات مدفوعة مقدماً، عربون، رصيد هدايا: كلها تُسجَّل كالتزام (deferred revenue) وتتحول لإيراد عند الاستخدام. تُبنى جاهزة للتدقيق من اليوم الأول.

"الأفضل على الإطلاق" يعني العمق

التميّز لن يأتي من عدد الميزات. يأتي من: عربي أصيل، عمل بدون إنترنت، محاسبة جاهزة للتدقيق، مساعد ذكي فوق بيانات موثوقة، وتجربة متقنة لكل نشاط. هذا ما لا يجمعه المنافسون معاً.

المساعد الذكي بحدود واضحة

يبدأ بالقراءة والتلخيص فقط. أي ذكاء يغيّر أسعاراً أو مخزوناً بدون موافقة بشرية يهدم الثقة في نظام محاسبي. وتكلفة النموذج تُحسب لكل استخدام، فلازم تدخل في تسعير الباقات.

التسعير التجاري

لا تحجب الـ modules الأساسية لنشاط العميل في باقة أعلى؛ هذا ينفّر. احجب الحجم: عدد الفروع، الجملة B2B، العروض المتقدمة، الـ API.

قرارات أحتاجها منك قبل البدء

هل توافق على الأنشطة التسعة للإطلاق (المعلّمة بـ ★)، أو تبغى تضيف أو تشيل؟

تذكير المواعيد والطلبات الجاهزة: WhatsApp Business API (تكلفة لكل رسالة عبر مزوّد معتمد)، أو SMS، أو الاثنين؟

صفحة حجز أونلاين عامة للعملاء (رابط للصالون أو السبا) في المرحلة C، أو لاحقاً؟

المساعد الذكي: مضمّن في كل الباقات بحد شهري، أو إضافة مدفوعة حسب الاستخدام؟

هل الـ modules مرتبطة بالباقات (Starter / Pro / Business)، أو كلها متاحة لكل باقة والفرق في الحجم فقط؟
